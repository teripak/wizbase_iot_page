서버구축, 게이트웨이, 기기등록이 없는
엣지 컴퓨팅 기술 상용화 Global 성공!

안전돌봄 IoT는 엣지 컴퓨팅(EDGE COMPUTING)과 MESH NERWORK 기술로 구성하여 SI구축 없이
전원 연결만으로 설치/운영/구성이 완료되며, 다양한 현장에서 유연하게 적용할 수 있도록 구성하였습니다.

EDGE DATA REPOSITORY

IoT가 측정한 모든 데이터가 개인 정보 유출이나 프라이버시 침해 없이 안전하게 댁내에 저장되는 '물리적 마이데이터' 실현

SERVERLESS

전원 연결만으로 대상자의 생활 환경을 바로 측정 불가역적 상태로 데이터 분산 저장
IoT간 초병렬 처리 기법으로 실시간 정보조회

MACHINE LEARNING

IoT 내에 머신러닝 엔진을 탑재하여 자가 보정 및 합의 알고리즘을 구현, 오탐지와 오작동을 제거하고 데이터 무결성을 확보

MESH NETWORK

IoT에 내장된 무선 인터넷 모뎀으로
즉시 서비스망에 접속하여
기기 간 인증/분산처리/데이터 보안 체계 구현

6 SENSORS + α

IoT 내 통합된 내장 센서로 움직임, 온도, 습도,
조도, CO2, tVOC 등 생활 환경 필수 정보를
정확하게 측정•기록하여 돌봄 서비스에 활용

WIRELESS INTERNET

돌봄 대상자의 다양한 환경(도서산간지역,
통신 음영지역)에 가장 폭넓게 적용할 수 있는
무선 인터넷을 제공

CORE VALUES

안전돌봄 IoT 구현의 3가지 핵심가치
